# Guia de exercícios — protótipo mobile-first (R$ 0)

Arquivo `index.html` é uma **prévia estática independente**, com busca local e fichas dos exercícios 01, 03 e 05. Não é ainda uma tela integrada ao aplicativo nem uma implantação pública. Pode ser aberto localmente em navegador, sem instalar dependências, sem login e sem API paga.

Dados derivados do piloto `../assets/jsr-fitness-premium/research/piloto-referencias.json` na data de criação. Para evitar carregamento remoto, os dados são embutidos no HTML; alterações no JSON **não sincronizam automaticamente** com esta página. Em futura integração, consumir o catálogo como fonte única.

Referências e classificações são preliminares, sem validação profissional. Os links para ACE são páginas de biblioteca e filtros, não necessariamente páginas específicas do exercício; confirmar a pertinência de cada referência antes de publicar conteúdo validado. Não foram copiados vídeos ou imagens de terceiros.

Próximo passo: conferir manualmente links e pertinência dos estudos, selecionar vídeos autorizados e integrar o componente ao MVP quando existir a interface principal.
